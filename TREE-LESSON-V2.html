11.1 Introduction to Trees & Forests

In discrete mathematics and graph theory, trees represent connected graphs free of cyclic loops[cite: 68, 69]. Arthur Cayley first studied them systematically in 1857 to count isomers of saturated hydrocarbons of the form CnH2n+2[cite: 68, 73].

Definition 1: The Graph-Theoretic Tree

A tree is a connected undirected graph with no simple circuits[cite: 69]. Because a tree cannot have a simple circuit, it contains no multiple edges or self-loops[cite: 69]. Therefore, every tree is a simple graph[cite: 69].

An undirected graph containing no simple circuits that is not necessarily connected is designated a forest[cite: 69]. Each connected component of a forest is a tree[cite: 69].

Theorem 1: Unique Simple Path

Theorem 1 (Section 11.1)

An undirected graph is a tree if and only if there is a unique simple path between any two of its vertices[cite: 69].

Proof Rationale:

  • If graph T is a tree, it is connected (so a simple path exists between any u, v)[cite: 70]. If two distinct simple paths existed, reversing one and concatenating it produces a circuit, contradicting the acyclic property[cite: 70].
  • Conversely, if there is a unique simple path between every pair, the graph is trivially connected[cite: 70]. If it had a simple circuit, any two nodes along the circuit would have two distinct paths, violating path uniqueness[cite: 70].

Theorem 2 & The Fundamental Equivalence Triad

Theorem 2 (Section 11.1)

A tree with n vertices has exactly n − 1 edges[cite: 75].

For any simple graph G = (V, E) with |V| = n, consider the Fundamental Triad[cite: 75]:

The Triad Conditions:
  1. G is connected[cite: 75].
  2. G has no simple circuits (acyclic)[cite: 75].
  3. G has exactly n − 1 edges[cite: 75].
The "Two-Out-of-Three" Law:

Any two conditions mathematically imply the third, and any pair definitively proves that G is a tree[cite: 75].

11.1 m-ary Trees, Height Bounds, & Balance

Definitions & Counting Theorems (Theorems 3, 4, 5)

A rooted tree is called an m-ary tree if every internal vertex has no more than m children[cite: 71]. It is a full m-ary tree if every internal vertex has exactly m children[cite: 71].

Theorem 3: A full m-ary tree with i internal vertices contains exactly n = mi + 1 vertices[cite: 75].

Theorem 4 Counting Formulas

In a full m-ary tree with n vertices, i internal vertices, and l leaves (n = i + l)[cite: 75, 76]:

  • Given n: i = (n − 1) / m and l = [(m − 1)n + 1] / m[cite: 76]
  • Given i: n = mi + 1 and l = (m − 1)i + 1[cite: 76]
  • Given l: n = (ml − 1) / (m − 1) and i = (l − 1) / (m − 1)[cite: 76]

Height & Balance (Theorem 5)

There are at most mh leaves in an m-ary tree of height h[cite: 77]. Thus, h ≥ ⌈logm l⌉; when full and balanced, h = ⌈logm l⌉[cite: 77].

11.2 – 11.5 Traversal, Search Trees, & Algorithms

Tree Traversals (11.3)

Systematic recursive vertex orders[cite: 96]:

  • Preorder: Visit Root → Left Subtree → Right Subtree (Prefix notation)[cite: 96, 103]
  • Inorder: Left Subtree → Visit Root → Right Subtree (Infix notation)[cite: 98, 103]
  • Postorder: Left Subtree → Right Subtree → Visit Root (Postfix / Reverse Polish notation)[cite: 99, 104]

Spanning Trees & MSTs (11.4 & 11.5)

  • Depth-First Search (DFS): Backtracking path exploration[cite: 108, 110, 111].
  • Breadth-First Search (BFS): Level-by-level queue traversal[cite: 112, 113, 114].
  • Prim's Algorithm: Grows MST by adding minimal incident edges from visited vertices[cite: 121, 122].
  • Kruskal's Algorithm: Merges forest components by greedily choosing overall minimal weight edges without cycles[cite: 122, 123, 124].
